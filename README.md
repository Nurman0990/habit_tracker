# Habit Tracker — Desktop App

Habit Tracker — это десктопное приложение для планирования, отслеживания повседневных привычек и визуализации личной продуктивности. Проект разработан на языке Python с использованием кроссплатформенного фреймворка Kivy и интеграцией с REST API.

---

Основной функционал

* **Управление привычками:** Создание, редактирование и отслеживание статуса выполнения ежедневных целей.
* **Аналитика и метрики:** Графическая визуализация прогресса и наглядные показатели выполнения задач.
* **Интеграция с REST API:** Взаимодействие с внешним сервером для передачи и синхронизации пользовательских данных.
* **Десктопный интерфейс:** Удобный кастомный GUI, адаптированный под работу на ПК.

---

Технологический стек

* **Язык программирования:** Python 3.x
* **GUI Фреймворк:** Kivy
* **Сетевое взаимодействие:** REST API (JSON / HTTP requests)
* **Среда разработки:** VS Code
